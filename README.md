# EscapeX — 18 Case Interactive Escape Room

## Structure
- 6 Easy cases
- 6 Medium cases
- 6 Hard cases
- Each case contains 3 rooms
- Each room contains 3 interactive puzzles
- Total: 18 cases, 54 rooms, 162 puzzle interactions

## Features
- Easy → Medium → Hard level selection
- 6 cases per level
- Progressive case locking/unlocking
- LocalStorage progress saving
- Progress dashboard
- Score and timer
- Hint system
- Inventory/evidence collection
- Interactive room objects
- Multiple visual room themes
- Animations and hover effects
- Web Audio API sound effects
- Responsive design

## Run
Open the folder in VS Code and use Live Server:
1. Right-click `index.html`
2. Select `Open with Live Server`

No external libraries are required.
